# Loom

Loom helps clients in the city get the outcome they came for, without the runaround.

**Built for:** Generic audience in the city

## Pages

- `index.html`
- `services.html`
- `about.html`
- `contact.html`

## Run locally

No build step required - it is a static site.

```bash
python -m http.server 8000
# then open http://localhost:8000
```

## Deploy

**GitHub Pages:** Settings -> Pages -> Source: `Deploy from a branch` -> Branch: `main` / `root`.

**Netlify / Vercel / Cloudflare Pages:** drag the folder in, or point at this repo.
No build command, publish directory `/`.

## Stack

Static HTML + Tailwind CSS (CDN) + vanilla JavaScript. Dark mode, responsive, no dependencies.
